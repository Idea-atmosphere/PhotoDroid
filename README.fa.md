# PhotoDroid: نسخهٔ اندروید PhotoCraft

[English](README.md) | **فارسی**

PhotoDroid پورت اندروید [PhotoCraft](https://github.com/storytold/photocraft) است و پوستهٔ اندروید، رابط لمسی گوشی، انتخابگر فایل سیستم، ذخیره‌سازی و گزارش تشخیصی خود را دارد. مجوز کد و دارایی‌های اصلی MIT OR Apache-2.0 است؛ فایل‌های مجوز، `NOTICE` و `ATTRIBUTION.md` را ببینید.

## همگام‌سازی با upstream

آخرین کامیت PhotoCraft که در این شاخه ادغام شده **`d2330fccea04d886c93fe7ee35757b72b5db6aff`** است؛ کامیت ادغام آن در PhotoDroid برابر `1ee4dd01a97ab448cef6cdba407d7c1f678a35ab` است. مبنای قبلی `cece50d5` بود. کامیت‌های بعدی PhotoDroid تغییرات اختصاصی اندروید را دارند؛ بنابراین قرار نیست فایل‌ها عین upstream باشند.

برای همگام‌سازی بعدی، PhotoCraft را fetch کنید و کامیت‌ها و تغییرات **بعد از** این مبنا تا هدف جدید را بررسی کنید. برای نمونه، پس از تنظیم remote به نام `upstream`:

```sh
git fetch upstream
git log --oneline d2330fccea04d886c93fe7ee35757b72b5db6aff..upstream/main
git diff --stat d2330fccea04d886c93fe7ee35757b72b5db6aff upstream/main
```

روی شاخه کار کنید، نه `main`. تغییرات مرتبط را ادغام کنید و پوستهٔ اندروید، چیدمان گوشی، ورودی لمسی، ذخیره‌سازی و گزارش تشخیصی PhotoDroid را حفظ کنید. تعارض‌ها را با بررسی هر دو طرف حل کنید و فایل‌های اختصاصی فورک را بدون بررسی جایگزین نکنید. برنامهٔ دسکتاپ، `crates/automation` و `crates/tablet`، workflowهای upstream، `xtask`، مستندات، book، scorecard و packaging خارج از این پورت اندروید هستند. بررسی‌کنندهٔ به‌روزرسانی و مجوز اینترنت را برنگردانید. ساخت اندروید و تست‌های میزبان و رابط را اجرا کنید، روی دستگاه بررسی کنید و مبنای بالا را فقط به هدفی که واقعاً ادغام شده تغییر دهید.

## مخزن و تست

- `crates/`: موتور و رابط مشترک با تغییرات اندروید.
- `apps/photocraft-android/` و `android/`: پوستهٔ Rust و Activity جاوا برای اندروید.
- `.github/workflows/android.yml`: ساخت APK برای arm64 و تست‌های میزبان و رابط؛ آن را روی شاخهٔ کاری اجرا کنید. APK به‌صورت artifact بارگذاری می‌شود.
- `Download/PhotoCraft/Projects` برای پروژه‌ها، `Output` برای سایر خروجی‌ها و `Fonts` و `log` به‌ترتیب برای فونت و گزارش تشخیصی هستند. Save As انتخابگر سیستم اندروید را برای انتخاب مکان باز می‌کند.

CI و تست دستگاه مکمل هم‌اند؛ موفقیت ساخت به‌تنهایی به معنی تأیید همهٔ قابلیت‌ها روی دستگاه نیست.
